# Societal OS Simulation

Dieses Verzeichnis enthält die Simulation des Societal OS.

## Dateien

- agent.py — Definition der Agenten (Mensch, Unternehmen, Infrastruktur)
- model.py — Hauptmodell (Kapitalflüsse, Rückkopplungen, Driftmessung)
- zero_growth_test/ — Testumgebung

## Startpunkte für Modellierer

Siehe:
- /docs/capital_flows.md
- /docs/architecture.md
- MODEL_REQUEST.md im Hauptverzeichnis

## Ziel

Die Simulation soll die sechs Motoren des Societal OS abbilden:
1. Existentiell
2. Finanziell
3. Realwirtschaftlich
4. Ökosystemisch
5. Eigentum/Erbe
6. Plattform

Modellierer können hier direkt einsteigen.
